# css-explorer
Application that explores CSS and shows users how to implement the styling by
providing both the shiny and CSS code needed.

## Environment
This application uses a {renv} set-up so install the package and run `renv::restore()`
to install and load the appropriate versions of the packages for this application.

## File structure
This application consists of ui, server and global R scripts that allow the application
to run and be interactive with user inputs and selections. There is also a subfolder 
**www/** that contains styling information for the application. This has the styles
sheet and image files that are used in the application
